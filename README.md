# Logica do projeto

## Essa parte contém o back do projeto!

# Tecnologias utilizadas:
- Java
- Spring

# Passo a passo:
1. Baixe o projeto.
2. Configure as variáveis de ambiente. Esse projeto pode rodar em Java 8.
3. Coleque o projeto do front e back na mesma pasta para facilitar.
4. O projeto está no repositorio como (interface-conferidor ).
5. Execute o projeto back JAVA primeiro, pode ser na run da IDE
6. Execute projeto o front.
